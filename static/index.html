Software Maintenance Taxonomy (IEEE 1219 / ISO 14764)

Post-delivery software evolution classifications governing lifecycle modifications

Category 1
Corrective Maintenance
Reactive modification performed to correct discovered design, logic, or runtime faults that halt software execution.
DevCore Reference: Null pointer exceptions, session expiration failures, and 504 gateway timeouts.
Category 2
Adaptive Maintenance
Modifications performed to adapt software to shifts in external environments, hardware, operating systems, or APIs.
DevCore Reference: High DPI layout scaling under Windows 11 and third-party SMS vendor payload limits.
Category 3
Perfective Maintenance
Proactive enhancement to elevate user experience, execution efficiency, and functional throughput.
DevCore Reference: Streaming CSV statement export alongside existing synchronous PDF generation.
Category 4
Preventive Maintenance
Code refactoring to isolate and neutralize latent faults before they manifest as runtime failures.
DevCore Reference: Enforcing strict context managers on SQLite connections to prevent pool exhaustion.
